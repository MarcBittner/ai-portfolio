## Notes

### What is solid
- **Citation validation**: `ask_twin` and `chat_twin` both intersect LLM-returned citation IDs against the retrieved set before returning; hallucinated chunk IDs are silently dropped and the test suite explicitly verifies this (`test_security.py:255–270`).
- **PII redaction gate**: `ingest_corpus` redacts before embedding and upserting; the API never returns raw PII values from the redaction preview endpoint; the `RedactionResult.mapping` is never logged.
- **Circuit breaker**: well-structured; the rate-limit (429) fast-path is correct; the half-open probe and `cooling_down()` implementation are sound.
- **Secret non-disclosure**: API keys are read from env vars, never echoed in `/health`, `/routing`, or error bodies; the `/routing` endpoint renders provider availability as booleans, not keys.
- **Input validation**: Pydantic models are used consistently; `persona_id` and `run_id` use slug/safe regex guards before any filesystem access.

### Deployment observation
The Cloud Run template (`deploy/cloudrun-service.yaml`) correctly shows secrets wired through Secret Manager rather than literal env values. No hardcoded secrets were found anywhere in the codebase.

### Out of scope
- CORS policy: no CORS headers are configured. This is acceptable for a same-origin deployment (frontend served from the same container), but should be revisited if the API is ever exposed to third-party frontends.
- Ollama/OpenRouter SSRF: `OLLAMA_BASE_URL` and `base_url` in extra providers are operator-controlled env vars, not user input; flagging this as SSRF would be a false positive for this architecture.
